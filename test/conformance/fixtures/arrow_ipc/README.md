# Arrow IPC interoperability fixtures

Generated by official PyArrow via `tool/conformance/arrow_ipc_interop.py`. Do not edit by hand.

Each fixture `<family>/<name>` has:

- `<name>.arrow`: Arrow IPC file format (omitted for stream-only cases such as
  dictionary replacement and delta dictionaries)
- `<name>.arrows`: Arrow IPC stream format
- `<name>.json`: expectation summary (schema, metadata, batch row counts,
  canonical per-row values). See the module docstring of
  `tool/conformance/arrow_ipc_interop.py` for the value encoding (64-bit integers and
  temporals as decimal strings, floats as raw bit hex, binaries as hex, ...).

`manifest.json` lists every fixture. Fixtures marked `optional` (body
compression) need not be supported by a writer.

```sh
P=.venv/bin/python  # python -m venv .venv && .venv/bin/pip install -r tool/conformance/requirements.txt
$P tool/conformance/arrow_ipc_interop.py generate            # rewrite fixtures
$P tool/conformance/arrow_ipc_interop.py check               # committed fixtures up to date
$P tool/conformance/arrow_ipc_interop.py verify --self-test  # oracle sanity
# Dart -> PyArrow: Dart writes <dir>/<family>/<name>.arrow|.arrows
$P tool/conformance/arrow_ipc_interop.py verify --output <dir> [--only primitive] [--require-all]
```

Notes:

- Extension types are compared unregistered (storage type plus
  `ARROW:extension:*` field metadata). Non-UTF-8 metadata values appear as
  `"hex:<bytes>"` in expectations.
- `structure/zero_columns` has zero fields and three rows.
- `--loose-batches` ignores batch boundaries and physical dictionary layout.
